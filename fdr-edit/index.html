1操作步骤

选择时间点 点击图表
在图表任意位置点击或拖动，红色游标会跳到该时刻，左侧所有参数自动切换到该点的值。
微调时间 ← →
使用键盘左右方向键，逐点移动游标。Home/End 跳转到首尾。
直接改值 点击右侧值框
图表右侧每个条带的值框都可直接点击编辑，回车确认，Esc 取消。
切换状态 下拉选项
对于告警、起落架等开关类参数，在左侧参数列表中使用下拉选项切换。
播放动画 空格 / ▶
点击播放按钮或按空格键，游标会自动前进，方便快速浏览整段记录。
缩放视图 + / −
横向缩放时间轴查看细节，纵向调整条带高度。点击“适应”恢复全览。
添加标签 时间点标签
在左侧“时间点标签”区域添加标记，用于标注关键时刻。
导出数据 LNFDR / PNG
导出为 LNFDR 数据文件以便二次编辑，或导出 PNG 图片用于分享存档。

2术语解析

FDR
飞行数据记录器Flight Data Recorder，“黑匣子”之一
GPWS
近地警告系统Ground Proximity Warning System，防止可控撞地
STALL
失速警告机翼迎角过大导致升力骤降
TCAS
空中交通防撞系统Traffic Alert and Collision Avoidance System
TA / RA
交通咨询 / 决断咨询TCAS 的两级警告，RA 会给出避让指令
N1
发动机低压转子转速以百分比表示，反映推力大小
EGT
排气温度Exhaust Gas Temperature，监控发动机健康
APPR
进近模式Approach，自动飞行捕捉航向道与下滑道
LOC
航向道Localizer，仪表着陆系统的水平引导
FLARE
拉平着陆前机头缓缓上仰，降低下降率
TD
接地Touchdown，主起落架接触跑道
Vref
着陆参考速度进近时的目标速度，通常为失速速度的 1.3 倍
提示：所有参数都可以修改。点击图表右侧的数值框直接编辑当前时刻的值；下拉选项类参数（如告警状态、起落架）请在左侧参数列表中切换。
